# RaiMS for Windows (x64)

`ms_server` is the Rai message service: one process that speaks Rendezvous
(rvd compatible), NATS, Redis and a telnet console, and meshes with other
ms_server instances.  This build is cross compiled on Linux with mingw-w64
(`make port_extra=-mingw dist_win`); the sibling libraries are linked in
statically, only the mingw runtime dlls in `bin\` are needed.

## Layout

```
bin\    ms_server.exe  ms_gen_key.exe  ms_test_adj.exe  raisvc.exe  *.dll
config\ startup.yaml + tport_{rv,nats,redis,tel}.yaml; svc_eval.yaml, param.yaml,
        config.yaml, .salt, .pass are generated by ms_gen_key (installer does it)
log\    ms_server.log (server log), ms_server.out (stdout/stderr via raisvc)
```

Evaluation transports (edit `config\tport_*.yaml`, restart the service):

| transport | listens on        | clients                                   |
|-----------|-------------------|-------------------------------------------|
| rv        | *:7500            | rvd clients: raisub2 -daemon tcp:7500 ... |
| nats      | *:4222            | any NATS client                           |
| redis     | 127.0.0.1:6379    | redis-cli, RESP clients                   |
| tel       | 127.0.0.1:2222    | telnet 127.0.0.1 2222 (console commands)  |

## Install

Run `raims-<ver>-win64-setup.exe`: it installs to `%ProgramFiles%\RaiMS`,
generates the service key with `ms_gen_key -d config -s eval -y` (only when
`config\svc_eval.yaml` does not exist yet, so keys survive upgrades), and
registers + starts the Windows service **RaiMS** (automatic start, restart on
failure after 5 s) through `raisvc.exe`.  Uninstall from *Apps & features*;
the config directory with the keys is left behind.

From the zip instead (as Administrator):

```
cd raims-<ver>-win64
bin\ms_gen_key -d config -s eval -y
bin\raisvc install RaiMS -w "%CD%" -l "%CD%\log\ms_server.out" -- "%CD%\bin\ms_server.exe" -d "%CD%\config" -l "%CD%\log\ms_server.log"
bin\raisvc start RaiMS
bin\raisvc status RaiMS
```

or just run it in a console: `bin\ms_server -d config -c`.

## raisvc

`raisvc` is a small generic wrapper that runs any console program as a
Windows service (the equivalent of a systemd unit with Restart=always):

```
raisvc install <name> [-w workdir] [-l logfile] [-D description] [-a auto|manual] -- <program> [args ...]
raisvc uninstall <name>
raisvc start|stop|status <name>
```

Stop sends the program a Ctrl-Break (ms_server shuts down cleanly on it) and
terminates it after 20 s if it has not exited.
